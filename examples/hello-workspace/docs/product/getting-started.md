# Getting started

This is a real, deliberately small BuildSteer workspace. It requires Node.js 20 or newer on this Mac.

1. In **Services**, start **Notes web service** and open its local URL.
2. In **Tests**, run **Node endpoint tests**. Expand the suite to run its test file separately.
3. In **Data Sources**, inspect **Notes JSON storage** and open `notes.json`.
4. In **Requirements**, open feature `001-notes`. Its requirements are linked to the service and tests.
5. In **Activity**, see the process and test events recorded by your actions.

The service starts only when you click Start. Local events and logs appear in `.productview/` in your copied workspace. No network account or secrets are needed.
