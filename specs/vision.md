# Product vision

Make software product development visible and understandable in one shared workspace.

OpenBuildRoom connects product intent with the code, services, tests, data and history in a repository. A product manager can shape the vision and roadmap, while coding agents and developers can read the same source of truth before making changes.

## For whom

Product managers and small software teams who want to build with coding agents while retaining a clear view of what exists, what is planned and why decisions were made.

## Guiding principles

- Keep the product context in the repository so every contributor can see it.
- Distinguish drafts, plans, work in progress and completed work.
- Show real runtime and test results separately from demo data.
- Make deployment plans reviewable before publishing a product.
